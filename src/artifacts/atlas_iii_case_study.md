# ATLAS-III Artifact Summary

This file provides a quick reference for the ATLAS-III mission artifacts generated by the Astraeus Apertura framework.

## Mission Profile

- **Mission**: ATLAS-III (Advanced Technology for Low-orbit Awareness and Surveillance)
- **Type**: Technology Demonstration
- **Platform**: 6U CubeSat
- **Orbit**: 500 km LEO, Sun-synchronous

## Primary Objective

Demonstrate space debris detection capability using an active X-band radar payload to support space situational awareness.

## Key Requirements Summary

| Category | Count | Key Items |
|----------|-------|-----------|
| Functional | 6 | Debris detection, radar operation, signal processing |
| Performance | 4 | 95% detection probability, 100m tracking accuracy |
| Interface | 4 | Power bus, data bus, communication interfaces |
| Environmental | 2 | Thermal range, radiation environment |
| Operational | 3 | Autonomous operation, duty cycle, data storage |
| Constraint | 4 | Mass (12kg), power (40W), form factor (6U) |
